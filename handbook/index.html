Hub Handbook

How the Bridgeman Downs Residents Hub (bdrv.au) is put together, how each part works, and how to look after it. Written in October 2026, eight months after the Hub was started in February 2026.

Please keep this handbook private This handbook is only linked from the Hub Admin page and is hidden from search engines. It contains no passwords or PINs, and it must never be given any. Those belong in the private Hub Secrets Register (a Google Doc kept outside the website), which this handbook points to but never copies.

Keeping this handbook up to date

The handbook lives in the handbook folder of the Hub’s GitHub repository, alongside the rest of the website, so it is backed up and versioned in the same way. When you add or change a feature:

  • Update the chapter for that system, and add or amend its row in the Page Directory.
  • If a new Google Sheet or Apps Script is involved, add it to Google Services.
  • If it creates a new regular job, add it to Routines.
  • Change the “Last reviewed” date at the foot of each page you edit.
