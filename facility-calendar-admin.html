🔁 Full Sync

Every add, edit or delete below already updates the calendar for that day automatically. Only use this if something looks out of step and you want to rebuild the whole calendar — it can take a few minutes.

🗓️ Recurring Activities

Fills in the standing weekly/fortnightly activities (from the Recurring Template tab) for the next few months, skipping anything already there. This also runs automatically once a month — use this if you want it brought up to date sooner. One-off events still need to be added by hand.

⚠️ Clash Check

Looks through all upcoming activities for two things booked in the same venue at overlapping times. You'll also get a warning when you save an activity that clashes. If two activities are meant to overlap, mark them as OK and they won't be flagged again.
