2 Manage your Help & How-To content
✍️ Fill in the details below to add a new question and answer to an existing category.
💡 Simple formatting tips: You can type a plain-English answer and it will work perfectly. If you want to add some structure, you can use these simple codes:
• New paragraph: wrap in <p>your text</p>
• Bold text: wrap in <strong>word</strong>
• Bullet point list: <ul><li>first item</li><li>second item</li></ul>
• Yellow tip box: <div class="tip-box">💡 <strong>Tip:</strong> your tip here</div>
📁 Use this to create a brand new topic section — for example, "How to Use Your Printer".
3 Download your updated file
⬇️ Click the button below to download your updated how-to.html file. Then go to your GitHub repository, find how-to.html, and replace it with this new version to publish your changes to the website.
